# FitPal Design System

## Theme
- Background: near-black / charcoal (#060709)
- Surfaces: dark card/surface (#0d0f14, #13161f)
- Accent: orange (#f97316, #fb923c, #ea580c)
- Text: white, light grey (#f3f4f6, #d1d5db, #9ca3af)
- Borders: subtle white/10

## Typography
- Font stack: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Segoe UI", system-ui, sans-serif
- Monospace: "JetBrains Mono", ui-monospace, SFMono-Regular, "SF Mono", Menlo, Monaco, Consolas, monospace

## Components
- CometCard: interactive 3D tilt for phone/mockups
- CanvasText: animated canvas text for hero emphasis
- TextGenerateEffect: word-by-word reveal for descriptions
- NoiseBackground: textured animated buttons/CTAs
- GlareCard: interactive glare for feature cards
- Floating glass navbar

## Effects
- Orange glow shadows
- Subtle noise texture
- Smooth framer-motion animations
- Respect prefers-reduced-motion
- No em dashes in UI copy

## Usage
- Hero: CanvasText for "Own Your Progress", TextGenerateEffect for description, CometCard for phone
- Features: GlareCard with orange accents
- CTAs: NoiseBackground buttons with orange gradients
- Feature pages: apply consistent theme, use CometCard for mockups where appropriate, use TextGenerateEffect for key descriptions
