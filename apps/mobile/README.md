# FitPal Mobile App

Mobile app for FitPal - Track your workouts, build routines, and own your progress.

## Getting Started

1. Install dependencies from root:
```bash
bun install
```

2. Start the development server:
```bash
cd apps/mobile
bun dev
```

3. Use Expo Go app on your device or run on emulator/simulator.

## Features

- Email/Password Authentication
- OTP Login
- Workout Logging
- Custom Routines
- Workout History (Logbook)
- Weekly Progress Tracking

## Tech Stack

- Expo SDK 52
- Expo Router (file-based routing)
- React Native
- TypeScript
- TanStack Query
- React Hook Form + Zod
- Axios
- Expo Secure Store
